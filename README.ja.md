# B2 TIC-VLA

[English](README.md) · [ドキュメント目次](docs/README.ja.md)

**Unitree B2**でTIC-VLAによるナビゲーションを評価する研究用リポジトリである．
言語指示に基づく経路予測を既存の歩行制御へ接続し，推論遅延の影響を測定する．
本プロジェクトは独立した統合の取り組みであり，論文著者・機体メーカーの公式配布物ではない．

## 範囲と現在地

利用できる構成はB2，外付けJetson AGX Orin，ZED 2i，Livox Mid-360である．
観測・推論・将来の上位制御はJetsonで行い，Macは開発・任意の結果表示に使う設計である．
準備したローカル実行では，Mac，大学Wi-Fi，クラウド推論を必須にしない．
内蔵センサー・サービスの役割と制御経路は，今後調査する必要がある．

リポジトリには，対象機の調査，合成再生，画像・状態取得のアダプター，組にした記録，
任意の同期オフライン推論がある．**これらのツールはモーター指令を送らない．**
ホスト構築とモデル不要のGPU・import検査は通ったが，実モデル読込，センサー・B2結合，
非同期ライブ制御，物理的停止は未検証である．重みは同梱・取得しておらず，
自律アプリも未導入である．記録済み観測，ライブ観測の順に進み，接続・停止の検証後に
管理された移動試験を行う．歩行方策の置換・学習は今回の範囲外とする．

概念，用語，確認済み仕様，環境構築，現地手順，進捗，次の作業は
[ドキュメント目次](docs/README.ja.md)から参照できる．全ガイドに対応する英語版を維持する．

## 準備用ツールを試す

ルートでPython 3.10以降を使えば，パッケージを導入せずに，追加依存のないCLIのヘルプと
ローカルのテストを実行できる．

```sh
PYTHONPATH=src python3 -m b2_tic_vla --help
PYTHONPATH=src python3 -m unittest discover -s tests -v
git diff --check
```

`replay`は合成入力を評価する．`camera`，`state`，`record`にはメーカーの動作する依存先と
確認済みの機器・通信設定が必要である．`infer`には別に承認した本家・モデルのローカル資材と，
確認した互換loaderが必要で，古い候補環境では現在モデル不要の検査に制限している．
依存先・資材は自動取得しない．合成・模擬テストは実機の性能を証明せず，設定例の値もB2の運用上限ではない．
