# B2 TIC-VLA

[English](README.md)

Unitree B2でTIC-VLAによるナビゲーションを評価するための研究用リポジトリ．
言語指示に基づくナビゲーションを機体の既存の歩行制御に接続し，モデルの推論遅延が動作に与える影響を測定する．

**現状は導入準備用ツールを実装した段階．** 対象機の調査，合成データの再生，カメラ画像の取得，
機体状態の購読，観測の記録，任意のオフライン推論確認に対応する．モーターへの指令は送らない．
実際のZED・B2での動作とGPU推論は未検証．本プロジェクトは独立した取り組みであり，
論文著者や機体メーカーによる公式配布物ではない．

## 今回の範囲

録画データによる確認から始め，次に移動指令を送らずに実機の観測から予測を確認する．
接続仕様と停止動作を検証した後，管理された環境でB2の走行実験を行う．新しい歩行方策の学習は今回の範囲に含めない．

利用できる構成はB2，Jetson AGX Orin，ZED 2i，Livox Mid-360である．Dockerと研究室GitHubの利用許可がある．
確定事項と次の調査は[進捗](docs/status.ja.md)にまとめる．
対象機に導入済みのソフトウェア，センサーの接続，座標系，時刻の対応は未確認である．
非同期の実機制御ループと，モーターへの指令送信部はまだ実装していない．

## 準備用ツールを試す

リポジトリのルートで，Python 3.10以降を使ってCLIとローカルのテストを実行できる．
このパッケージ自体のインストールは不要である．

```sh
PYTHONPATH=src python3 -m b2_tic_vla --help
PYTHONPATH=src python3 -m unittest discover -s tests -v
git diff --check
```

単独で使える環境調査ツールは，Python 3.8以降と標準ライブラリだけで動く．
パッケージ全体と切り離して対象機にコピーできる．

```sh
python3 tools/inspect_target.py --help
```

| CLIコマンド | 用途 | 追加で必要なローカル環境 |
| --- | --- | --- |
| `replay` | 合成軌道と入力の拒否条件を評価する．ニューラルモデルは使わない | なし |
| `camera` | ZEDの左カラー画像を保存する | 接続済みカメラ，対応するZED SDKとPython binding |
| `state` | Unitreeのsport stateを購読する | 動作するSDK2・DDS環境と，明示したネットワークインターフェース |
| `record` | 画像と，対応して受信した機体状態を保存する | カメラと状態取得の両方の環境 |
| `infer` | 既存のローカルモデルを使って同期推論を確認する | 互換性のある上流TIC-VLAパッケージ，モデルの依存先，重み，GPU |

引数と結果の読み方は[現地での準備](docs/onsite.ja.md)を参照する．
依存パッケージとモデルファイルは自動取得しない．設定例の上限値は未検証の試験用であり，B2の運用で承認された値ではない．
ローカルのテストは合成入力と任意依存先のモックを使うため，センサー，モデル，機体の性能を確認するものではない．

## ライセンスと公開

独自に作る成果物の権利者とライセンスは未定．研究室GitHubの利用許可はあるが，接続先と可視性はまだ指定されていない．
現在はローカルで管理している．
上流のソースコード，モデルの重み，録画，研究室のデータは含めていない．
将来このプロジェクトに付けるライセンスは，外部資料の利用条件を置き換えるものではない．

文書の作成にはAIを利用している．研究資料として内容をレビューする必要があり，文書自体を実験の証拠として扱わない．
